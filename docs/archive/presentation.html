Real-Time Industrial Intelligence

Agentic AI-Based Predictive Maintenance Dashboard for Industrial Machines

A real-time predictive maintenance platform that takes dataset or simulated sensor input, preprocesses it, predicts machine condition using ML, and uses an LLM orchestrator to activate the right agents for normal, warning, or critical cases.

Streamlit Dashboard LLM-Orchestrated Agents Live and CSV Data Support ML Condition Prediction Industrial Monitoring

Problem Statement

Industrial machines often fail without enough warning. Traditional maintenance is either reactive or schedule-based, which leads to unplanned downtime, unnecessary servicing, and poor visibility into developing machine risk.

Unexpected Breakdowns

Failures interrupt production and create expensive emergency maintenance situations.

High Maintenance Cost

Routine servicing may happen too early while hidden problems still develop between inspections.

Limited Condition Visibility

Operators do not always have a clear picture of machine health across multiple assets.

Slow Decision Making

Teams need diagnostic context and action guidance, not just raw sensor values.

How the System Solves It

Real-Time Monitoring

Tracks machine status continuously using live or uploaded sensor readings and surfaces abnormal conditions early.

Agentic AI Reasoning

Uses an LLM orchestrator to decide which agents should run after the ML model predicts Normal, Warning, or Critical condition.

Actionable Outputs

Transforms sensor behavior into condition labels, activated agent outputs, root causes, recommended actions, repair steps, and dashboard updates.

Project Value

The dashboard helps reduce downtime, lower maintenance cost, improve operational efficiency, and enable data-driven decisions through intelligent condition-based maintenance.

Project Workflow

Input Data

The system takes input from a dataset or simulated sensor readings such as temperature, vibration, and pressure.

Preprocess Data

The raw data is cleaned, normalized, and prepared so it can be used reliably for analysis.

Predict Condition

The ML model predicts the machine condition as Normal, Warning, or Critical. It gives a signal, not the final decision.

Orchestrate Agents

The LLM orchestrator reads the ML output and decides which agents should be activated for the current condition.

Normal Condition

Only the Monitoring Agent is active, and the dashboard is updated directly with a healthy machine status.

Warning Condition

The Diagnostic Agent identifies the possible issue, and the Decision Agent suggests preventive actions.

Critical Condition

All agents run in sequence: monitoring confirms the issue, diagnostics find the root cause, decisions choose actions like stopping the machine, and the planner gives repair steps.

Dashboard, Chat, and Storage

Results are shown on the dashboard, the Chat Agent answers user questions separately, and all data, predictions, and outputs are stored for future use.
